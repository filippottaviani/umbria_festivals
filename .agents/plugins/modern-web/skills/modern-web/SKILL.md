# Modern Web Framework Skill

Guide for developing modern, full-stack web applications with high performance, strict type safety, and clean separation of concerns.

## Core Practices

1. **Frontend Architecture**:
   - Component-driven architecture (atomic/feature-based organization).
   - React hooks, functional state management, and type-safe props.
   - Clean handling of loading spinners, skeletal states, error messages, and empty data lists.

2. **Backend Integration**:
   - Fast, asynchronous Python (FastAPI/Uvicorn) or Node.js endpoints.
   - Pydantic/TypeScript schema parity for request/response bodies.
   - Environment variable management for API keys and connection strings.

3. **Code Quality**:
   - DRY (Don't Repeat Yourself) principle.
   - Strict TypeScript / Python type hints.
