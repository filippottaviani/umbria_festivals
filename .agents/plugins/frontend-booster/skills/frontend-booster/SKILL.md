# Frontend Booster Skill

Enhance web development workflows with production-grade frontend practices.

## Guidelines

1. **Design System & Styling**:
   - Utilize curated color palettes and modern typography.
   - Implement fluid layouts with Flexbox and CSS Grid.
   - Use CSS custom properties (variables) for theme consistency.

2. **Component Architecture**:
   - Modular, re-usable component structures.
   - Immutable props and controlled inputs.
   - Error boundaries and graceful fallback UI states.

3. **Performance & Accessibility**:
   - Semantic HTML tags (`<header>`, `<main>`, `<footer>`, `<section>`).
   - Accessible interactive controls with proper ARIA attributes and focus management.
   - Optimized image loading (`loading="lazy"` and explicit aspect ratios).
